GET STARTED

Installation & setup.

Download the app, connect your SpyderX, and measure. Python, PsychoPy and the plotting tools are already included in both downloads.

WindowsLinuxFirst measurementUse in PsychoPySave files

Windows

  1. Download the Windows ZIP (64-bit).
  2. Right-click the ZIP and choose Extract All. Open the extracted Spyder Cal folder.
  3. Double-click Spyder Cal.exe. Keep all the other files and the resources folder beside it.
  4. Plug in the SpyderX, close other programs using the sensor, and press Connect in the app.

No separate Python, Node.js or PsychoPy installation is needed.

USB driver

The SpyderX needs a WinUSB or libusbK driver. If Connect succeeds, the driver is ready. Otherwise, check the device in Windows Device Manager.

If a compatible driver is missing, use Zadig: choose Options → List All Devices, select Datacolor SpyderX with USB ID 085C:0A00, and install WinUSB or libusbK. Check the device and ID before changing its driver. Reconnect the sensor and try Connect again.

Single-file portable alternative

The portable .exe needs no manual extraction. It shows a loading panel while unpacking its runtime on every launch, which can take tens of seconds. The ZIP is recommended for faster repeated startups.

Linux

The x86_64 AppImage was built on Ubuntu 22.04. Use a graphical desktop with working OpenGL. Download it, then run these commands from your Downloads folder:

cd ~/Downloads
chmod +x Spyder-Cal-linux-x86_64.AppImage
./Spyder-Cal-linux-x86_64.AppImage

Download the Linux AppImage

USB access

Install libusb and the supplied udev rule so the app can access the SpyderX as your normal desktop user. On Ubuntu 22.04:

sudo apt update
sudo apt install libusb-1.0-0
curl -fsSLO https://raw.githubusercontent.com/raffaelemazziotti/spyder_cal/main/udev/60-spyderx.rules
sudo install -m 644 60-spyderx.rules /etc/udev/rules.d/60-spyderx.rules
sudo udevadm control --reload-rules
sudo udevadm trigger

Unplug and reconnect the sensor, then press Connect. The rule grants access to the active desktop user through uaccess, with plugdev as a group fallback. If your distribution uses another device-access group, adapt the rule. Run the app as your normal user.

FUSE or missing system libraries

If FUSE is unavailable, use the AppImage's extraction mode:

./Spyder-Cal-linux-x86_64.AppImage --appimage-extract-and-run

On Ubuntu 22.04, missing desktop libraries can be installed with:

sudo apt install libgtk-3-0 libnss3 libasound2 libgl1

Package names vary on other distributions. See the AppImage FUSE guide for more options.

The Linux runtime, exports and PsychoPy window have been checked on Ubuntu 22.04 under WSL. Physical SpyderX USB measurements still need verification on a native Linux installation.

Your first measurement

  1. Let the display warm up. Keep brightness, contrast, HDR, adaptive brightness, Night Light and any existing color calibration fixed during measurement and experiments.
  2. Press Connect. Choose a Screen and use Test screen to confirm the display. Screen numbering follows PsychoPy.
  3. Set the monitor name, gray levels, repetitions and settling time. Enable the corrected measurement to verify linearization.
  4. Press Measure. Follow the instructions in the fullscreen PsychoPy window: cover the sensor for dark calibration, then uncover it and place it at the center of the display. Press Space when prompted. Escape cancels.
  5. At completion, remove the sensor and press Space to return. The left plot shows the original measurements; the right shows actual measurements with inverse-gamma-corrected patch values.

All measurement instructions stay in the PsychoPy window, including on a single-monitor computer. The app measures grayscale gamma; it does not measure separate red, green and blue gamma curves.

Use the value in PsychoPy

Use Copy in the Gamma card and enter that original measured exponent in PsychoPy's Monitor Center. You can also set it when creating a Python experiment window:

from psychopy import visual

# Replace 2.215 with your measured original gamma.
win = visual.Window(screen=0, fullscr=True, gamma=2.215)
# Present your experiment stimuli here.
win.close()

Use the measured exponent, not its reciprocal or the corrected curve's exponent. The app verifies correction through patch pixel values; PsychoPy's window setting uses the display gamma table. Support depends on the OS and graphics backend, so measure the final experiment output to verify it.

See PsychoPy's gamma correction guide and Window API. The app does not install a system color profile.

Save and repeat

Save files exports a JSON session, a CSV of every reading, and PNG/SVG plots. Copy buttons in the summary cards copy individual values. Luminance is in cd/m²; corrected error is RMSE as a percentage of the original luminance range.

Use New for another measurement, or Open → Recent measurements to revisit a completed session. Open → Open file loads an app-exported JSON. The Python library's JSON uses a different schema; see the Python API guide.
