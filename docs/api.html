Install from source

Clone the repository and run scripts from its root so Python can import cal_lib.py and cal_psy.py. The library is not installed as a package by these commands. The examples below use Python 3.10 and PsychoPy 2026.2.5, as tested for this release.

git clone https://github.com/raffaelemazziotti/spyder_cal.git
cd spyder_cal

Windows · PowerShell

py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install "psychopy==2026.2.5" -r requirements.txt
.\.venv\Scripts\python.exe Demo.py --screen 0 --repetitions 3

Install the SpyderX USB driver if needed. The Windows requirements include the libusb DLL through libusb-package.

Linux · Ubuntu 22.04

sudo apt install python3.10-venv libusb-1.0-0
python3.10 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install "psychopy==2026.2.5" -r requirements.txt
.venv/bin/python Demo.py --screen 0 --repetitions 3

Set up udev USB access before measuring. PsychoPy needs a graphical desktop and native display dependencies; consult its installation guide if a dependency cannot be installed. The standalone app includes these Python dependencies.

For direct USB reads or fitting without PsychoPy, install requirements-usb.txt instead of the full requirements. Select the same .venv interpreter in your editor or use its Python executable when running your scripts.

Measure display gamma

This opens a PsychoPy window, guides dark calibration and sensor placement, and measures independent sweeps from black to white.

from cal_lib import SpyderX

with SpyderX() as spyder:
    result = spyder.measure_gamma(
        repetitions=3,
        num_levels=12,
        pause=1.0,
        screen=0,
        fullscr=True,
    )
    result.save_json("gamma.json")

print(f"Gamma: {result.gamma:.3f} (SD {result.gamma_std:.3f})")
print(f"Black: {result.luminance_min:.3f} cd/m²")
print(f"White: {result.luminance_max:.3f} cd/m²")

Follow the fullscreen prompts and press Space to confirm. with SpyderX() releases the USB interface when the block ends, including when an error occurs. measure_gamma() closes its own PsychoPy window.

measure_gamma() options
ParameterDefaultMeaning
repetitions3Independent sweeps; at least 1.
num_levels12Gray levels, including black and white; at least 3.
pause1Settling seconds before each read; nonnegative.
screen0PsychoPy display index; use 1 for another display if available.
fullscrTrueUse the selected display fullscreen.
size, posNoneOptional window size/position in pixels. Without size, fullscreen uses native resolution.
dark_calibrationTruePrompt for covered-sensor calibration. Disable only after calibrating this sensor instance yourself.

These Python sweeps measure the original response. For the complete original/corrected measurement workflow with paired plots and exports, use the desktop app. To apply the measured exponent in an experiment, see Use in PsychoPy.

Results and JSON

measure_gamma() returns a GammaMeasurement. Gamma and luminance summaries are arithmetic means across repetitions; standard deviations are sample SDs, or zero for a single repetition.

Attribute / methodContents
gamma, gamma_stdMean fitted exponent and its SD.
gamma_valuesOne exponent per repetition.
luminance_min, luminance_maxMean per-run minimum and maximum, in cd/m².
luminance_min_std, luminance_max_stdSDs of those per-run extrema.
runsList of dictionaries: repetition, gamma, gray_levels, luminance and fit_parameters.
to_dict()JSON-serializable dictionary, including every reading.
save_json(path)Atomically writes JSON, creates parent directories, returns an absolute pathlib.Path.

Each run's gray_levels contains the original PsychoPy values from −1 to +1. Luminance samples are cd/m². Fitted parameters are [a, b, c] for the normalized model y = a * x**b + c; gamma is b.

import json

with open("gamma.json", encoding="utf-8") as file:
    data = json.load(file)

print(data["gamma"])
print(data["gamma_by_repetition"])
print(data["luminance"]["maximum"])
print(data["runs"][0]["luminance"])

Python library JSON uses schema_version: 2. Desktop app sessions have a different schema containing original/corrected sweeps and settings; the app's Open command expects those app sessions. Both formats expose a top-level gamma scalar.

Read luminance directly

No PsychoPy window is opened by the low-level sensor API. You control the displayed stimulus and allow it to settle before reading.

from cal_lib import SpyderX

with SpyderX() as spyder:
    input("Cover the sensor, then press Enter: ")
    spyder.calibrate()
    input("Uncover it and place it on your stable display patch, then Enter: ")
    luminance = spyder.get_luminance()
    print(f"Luminance: {luminance:.3f} cd/m²")
    xyz = spyder.measure()  # a new reading: NumPy array [X, Y, Z]

Call calibrate() with the lens covered before the first reading. get_luminance() returns the Y component of a new XYZ measurement. get_rgb_luminance() returns an approximate linear RGB tuple from a new reading; it is not a display RGB calibration.

Usually SpyderX() discovers libusb automatically. An explicit shared-library path is also accepted, for example SpyderX(libusb_path=r"C:\path\to\libusb-1.0.dll") on Windows.

Fit existing measurements

GammaFitter needs neither a sensor nor PsychoPy. Supply equal-length intensity and luminance arrays with a nonzero range in both. It normalizes each array to 0–1 and fits a power law with scale and offset.

import numpy as np
from cal_lib import GammaFitter

# Illustrative data; replace with your measured samples.
intensity = np.linspace(0, 1, 12)
luminance = 0.2 + 120 * intensity**2.2
fit = GammaFitter(intensity, luminance)
parameters = fit.fit()  # [scale, gamma, offset] in normalized units
print(fit.gamma)
fit.plot()

Before fit(), use set_bounds(lower_bounds, upper_bounds) or set_initial_guess(initial_guess) to customize the three model parameters. plot() displays the readings and fit on the original scales.

Control PsychoPy gray levels

Use GrayLevels for custom measurement sequences. It owns its PsychoPy window; the sensor can be managed separately.

from cal_lib import SpyderX
from cal_psy import GrayLevels

with SpyderX() as spyder:
    levels = GrayLevels(spyder, fullscr=True, screen=0, size=None)
    try:
        levels.calibrate()
        fit = levels.measure(num_levels=12, pause=1, plot=False)
        print(fit.gamma)
    finally:
        levels.close(close_spyder=False)

measure(pause=1, gamma=None, num_levels=12, wait_user=True, plot=True) returns a fitted GammaFitter. Set wait_user=False for another sweep without repeating the placement prompt. The optional gamma requests PsychoPy display-table correction and depends on the OS/backend; it is distinct from the app's pixel-value correction.
